# Fish Mya Auto Bot Modified

Fish Mya game အတွက် အလိုအလျောက် ကစားပေးသည့် bot ဖြစ်ပါသည်။

## Features
- Auto Shooting (Ultra Fast)
- Auto Rejoin Room
- Coin Balance Tracking
- Modified Logic: 100k/s Bullet Consumption, 2/3 Kill Rate

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set environment variable:
   - `TELEGRAM_TOKEN`: Your Telegram Bot Token
3. Run the bot:
   ```bash
   python bot.py
   ```
